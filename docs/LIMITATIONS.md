# Limites et dettes scientifiques V0.1

1. Les coordonnées des écoles et économistes sont des **seed codings** structurés, pas un résultat d’accord inter-codeurs.
2. Les 12 dimensions sont théoriquement motivées mais leur indépendance empirique n’est pas démontrée.
3. La distance euclidienne normalisée est un baseline explicable, pas une métrique validée.
4. Les fiches du site sont descriptives mais ne remplacent pas encore les monographies académiques longues prévues pour la V1 publication.
5. Les items n’ont pas encore de paramètres psychométriques empiriques; leur pouvoir discriminant est estimé à partir du référentiel doctrinal.
6. Le corpus V0.1 reste plus fort sur les traditions européennes et nord-américaines; le registre des candidats documente plusieurs lacunes à traiter.

Ces limites sont volontairement visibles : les masquer donnerait une précision fictive au projet.
