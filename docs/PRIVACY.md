# Confidentialité

Le test principal est conçu pour fonctionner entièrement dans le navigateur. Aucun compte n’est nécessaire et aucune réponse brute n’est transmise par défaut.

Fonctions serveur facultatives futures : sauvegarde volontaire, compte, profil public opt-in et contribution anonymisée au corpus scientifique. Ces finalités doivent être séparées et consenties explicitement.

Un profil partagé ne doit jamais exposer les réponses brutes sans action volontaire distincte.
