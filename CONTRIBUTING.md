# Contribuer

Les contributions de code et les contributions doctrinales suivent des chemins différents.

- Code : PR + tests + absence de changement silencieux de la méthode.
- Profil doctrinal : sources primaires/secondaires, justification par dimension, auteur du codage, reviewer indépendant.
- Question : dimension visée, polarité, justification, risque d’amorçage, statut pilote/validé.

Aucune PR ne doit modifier un profil uniquement pour obtenir une classification jugée plus intuitive.
